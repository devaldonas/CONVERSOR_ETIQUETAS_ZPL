# ZPL Converter

Sistema web para converter XML em etiquetas ZPL para impressão em impressoras Zebra.

## Tecnologias
- Node.js
- Supabase (PostgreSQL)
- HTML + JavaScript
- XML → ZPL

## Funcionalidades
- Upload de XML
- Preenchimento automático de campos
- Geração de ZPL
- Download do arquivo .zpl

## Como rodar
1. Configurar backend
2. Criar arquivo .env
3. Executar:
   npm install
   node server.js
4. Abrir o frontend no navegador
